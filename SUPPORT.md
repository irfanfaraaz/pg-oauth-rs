# Getting help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/irfanfaraaz/pg-oauth-rs/discussions).
- **Bugs:** open an issue with the Bug report form.
- **Security problems:** follow [SECURITY.md](SECURITY.md). Never post them in public.

This is a volunteer project. There is no paid support and no response-time promise.

When you ask for help, never paste a token, password or client secret.
